Agents that forget the last run are toys. The useful ones keep facts, and they search a workspace knowledge base, without you wiring a store and a RAG pipeline for every graph.

That is a host problem. The graph should ask for memory. Linea should keep it.

If the store is yours to operate, you are still writing glue. We built Linea so that part comes with the run.
