Technical builders need a code node. Visual tools that pretend otherwise thin out the first time a step needs real logic.

The cost is where that code runs. A process you host yourself is a process you babysit. Linea sandboxes the escape hatch so the graph can stay on the graph.

You write the function. The runtime keeps it in a box.
